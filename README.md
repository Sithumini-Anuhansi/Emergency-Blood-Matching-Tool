\# 🩸 Emergency Blood Network



A graph-based emergency blood donor matching system developed as part of the \*\*Data Structures\*\* module.



This repository contains \*\*two phases\*\* of the project:



\- \*\*Phase 1:\*\* Java Console Application (Data Structures Prototype)

\- \*\*Phase 2:\*\* Android Mobile Application (Enhanced User-Friendly System)



The project demonstrates how the \*\*Graph\*\* data structure and \*\*Dijkstra's Shortest Path Algorithm\*\* can be applied to solve a real-world healthcare problem by identifying the nearest compatible blood donors during emergencies.



\---



\# 📌 Project Overview



Blood shortages and delays in locating compatible donors are common challenges during medical emergencies. Traditional methods often rely on manual communication, outdated donor lists, or social media, which can significantly increase response time.



The Emergency Blood Network was developed to streamline this process by allowing hospitals to submit emergency blood requests while automatically identifying compatible donors and nearby blood banks using graph-based shortest path calculations.

\# 🧩 Data Structure Used



\## Graph



The project is based on the \*\*Graph\*\* data structure.



\### Vertices



\- Hospitals

\- Blood Donors

\- Blood Banks



\### Edges



\- Roads connecting locations

\- Weighted using travel distance



\### Algorithm



\- Dijkstra's Shortest Path Algorithm



The graph enables the application to determine the nearest compatible donor while minimizing travel distance and emergency response time.
